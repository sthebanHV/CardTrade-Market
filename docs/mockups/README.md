- **Labels**: 12-13px, weight 500, uppercase
- **Small**: 11-12px, weight 400

## Tamaños de Vista

- **Desktop**: `viewBox="0 0 1200 900"` (o 1000/1100 según contenido)
- **Mobile**: `viewBox="0 0 375 812"` (no incluido, solo desktop)
- **Modales**: `viewBox="0 0 1200 600"` con overlay

## Cómo Visualizar

1. Abre cualquier archivo `.svg` en el navegador
2. O arrástralo a una pestaña del navegador
3. Para ver en GitHub, los archivos se renderizan automáticamente
